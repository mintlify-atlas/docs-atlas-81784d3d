Harvey is an autonomous sales agent that runs on your machine. It finds businesses worth selling to, learns something specific about each one, writes cold email that references it, sends it, reads the replies, and works the conversation toward a meeting — all in a heartbeat loop you control.

The unusual part: **there is no model API bill.** Harvey uses your Claude Pro/Max subscription through Claude Code, or your ChatGPT subscription through Codex. Model calls draw from the plan you already pay for — no API key, no per-token charges.

## What Harvey does

Harvey runs a heartbeat loop — wake up, check the budget, decide what most needs doing, do it, log it, sleep. Every 15 minutes by default.

```
                 ┌──────────────────────────────────────┐
                 ↓                                      │
   Wake  →  Quiet hours?  →  Budget OK?  →  Decide  →  Act  →  Log  →  Sleep
                 │               │
              (sleep)         (sleep)
```

It decides deterministically from pipeline state — no model call needed for something derivable from four counts:

```
handle replies  >  send campaigns  >  write campaigns  >  prospect  >  idle (analyze)
```

## Get started

<Steps>
  <Step title="Install Harvey">
    Clone the repo, create a virtual environment with Python 3.11+, and install dependencies.
    ```bash
    git clone https://github.com/ethanplusai/harvey.git
    cd harvey
    python3.13 -m venv .venv && source .venv/bin/activate && pip install -e .
    ```
  </Step>
  <Step title="Configure your product and ICP">
    Copy `.env.example` to `.env`, fill in your mail credentials, then train Harvey on your website.
    ```bash
    cp .env.example .env
    harvey train https://your-company.com
    ```
  </Step>
  <Step title="Confirm your signals">
    Tell Harvey which of its 23 prospect signals you want to collect. Nothing is gathered until you confirm.
    ```bash
    harvey signals --confirm free
    ```
  </Step>
  <Step title="Run Harvey">
    Start the dashboard in one terminal, then launch the heartbeat loop.
    ```bash
    harvey dashboard   # opens http://127.0.0.1:5555
    harvey run
    ```
  </Step>
</Steps>

<Note>
  Harvey uses your existing Claude or Codex subscription for all model calls. You need a Claude Pro/Max account with the Claude CLI installed (`claude login`), or a ChatGPT plan with the Codex CLI for the Codex provider.
</Note>
